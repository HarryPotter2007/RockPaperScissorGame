# ✊🖐️✌️ Rock Paper Scissors Game (Java)

A simple **Rock Paper Scissors** game made using **Java** where you play against the computer.
The computer randomly chooses between **rock / paper / scissors** and the game keeps track of your points.

---

## ✅ Features

- User vs Computer gameplay
- Random computer moves using `Random`
- Input validation (invalid move check)
- Score system (points increase when you win)
- Play again option (yes/no)
- Displays total score at the end

---

## 🛠️ Tech Used

- **Java**
- `Scanner` for user input
- `Random` for computer choice

---

## 📌 How the Game Works

- User enters: `rock` / `paper` / `scissors`
- Computer chooses randomly
- Winner is decided:
  - Rock beats Scissors
  - Scissors beats Paper
  - Paper beats Rock
- If both choose same → Tie
- Points increase only when user wins ✅
